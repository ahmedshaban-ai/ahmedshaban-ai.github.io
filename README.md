# Ahmed Sha'ban — AI Research Hub v2

A premium animated personal research portfolio for GitHub Pages.

## Included

- Intro animation
- Animated particle network
- Mouse-following light effect
- Typing animation
- 3D tilt cards
- Magnetic buttons
- Animated counters
- Reveal-on-scroll effects
- Moving technology marquee
- Research cards and project showcase
- Responsive mobile navigation
- Downloadable CV
- GitHub and LinkedIn links

## Deploy

Create a public repository named:

`ahmedshaban-ai.github.io`

Upload the contents of this package to the repository root, then go to:

`Repository Settings → Pages → Deploy from a branch → main → /(root)`

The live website will appear at:

`https://ahmedshaban-ai.github.io`

## Important

Upload the files themselves to the root. Do not upload the outer folder as a nested folder.
