# Ahmed Sha'ban — AI Research Hub

A polished personal research portfolio built with HTML, CSS, and JavaScript and designed for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new public repository named:

   `ahmedshaban-ai.github.io`

2. Upload all files from this package to the repository root.

3. Open:

   `Settings → Pages`

4. Under **Build and deployment**, select:

   `Deploy from a branch`

5. Choose:

   `main` and `/ (root)`

6. Save. Your website will appear at:

   `https://ahmedshaban-ai.github.io`

## Files

- `index.html` — website structure and content
- `style.css` — responsive design and visual effects
- `script.js` — typing animation, particles, counters, reveal effects, mobile menu
- `assets/research-banner.png` — portfolio banner
- `assets/Ahmed_Shaban_CV.pdf` — downloadable CV

## Update Links

Search for `ahmedshaban-ai` in `index.html` and replace it if your final GitHub username is different.

## Local Preview

Open `index.html` directly in a browser, or use the VS Code Live Server extension.
